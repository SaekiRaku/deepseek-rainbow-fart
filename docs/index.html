天空为什么是蓝色的？

DS
DeepSeek Agent

天空呈现蓝色，主要与太阳光进入大气层后的瑞利散射有关。

空气分子更容易散射波长较短的蓝光。来自各个方向的蓝光进入眼睛，于是我们看到了一片蓝色天空。
